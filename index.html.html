Pendahuluan: Kabel LAN / Ethernet

Kabel LAN (Local Area Network) atau dikenal juga sebagai kabel Ethernet adalah media transmisi fisik berbentuk kabel yang digunakan untuk menghubungkan berbagai perangkat komputer (seperti Laptop, PC, Router, dan Switch) dalam suatu jaringan area lokal.


Kabel LAN mentransmisikan sinyal data elektronik dari satu perangkat ke perangkat lainnya dengan kecepatan tinggi dan stabilitas yang jauh lebih baik dibandingkan jaringan nirkabel (Wi-Fi).

Alat dan Bahan Perakitan

1. Kabel UTP (Cat5e / Cat6)

Kabel berpasangan terpilin tanpa pelindung yang berisi 8 helai kawat warna-warni sebagai jalur transmisi data.

2. Konektor RJ-45

Konektor standar di kedua ujung kabel yang dimasukkan ke port LAN pada komputer/switch.

3. Tang Crimp (Crimping Tool)

Alat pemotong, pengupas kabel, dan pengunci pin tembaga konektor RJ-45 ke kawat kabel.

4. LAN Tester

Alat uji untuk memverifikasi apakah seluruh 8 pin terhubung dengan benar dan tidak ada arus terputus.

Cara Membuat Kabel LAN (Tipe Cross-Over)

Kabel Crossover digunakan untuk menghubungkan dua perangkat yang sejenis (seperti Laptop ke Laptop) secara langsung tanpa Switch/Hub.


Urutan Pin Warna Kabel:

Pin Ujung A (Straight T568B) Ujung B (Cross T568A)
1Putih-OranyePutih-Hijau
2OranyeHijau
3Putih-HijauPutih-Oranye
4BiruBiru
5Putih-BiruPutih-Biru
6HijauOranye
7Putih-CokelatPutih-Cokelat
8CokelatCokelat

Langkah-Langkah Pembuatan:

  1. Kupas jaket pelindung kabel UTP sepanjang 2 cm menggunakan tang crimp.
  2. Luruskan dan pisahkan 8 helai kawat warna-warni di dalamnya.
  3. Urutkan susunan warna kawat sesuai standar T568B pada Ujung A dan T568A pada Ujung B.
  4. Ratakan dan potong rapi ujung kawat hingga tersisa sekitar 1.2 cm.
  5. Masukan kawat ke dalam konektor RJ-45 hingga seluruh ujung kawat menyentuh dasar konektor.
  6. Jepit konektor RJ-45 menggunakan tang crimp hingga terdengar bunyi klik.
  7. Uji kedua ujung kabel menggunakan LAN Tester. Pada tipe Cross, lampu LED akan menyala silang (1-3, 2-6, 3-1, 6-2).

Menghubungkan 2 Laptop & Transfer File

Step 1: Setting IP Address Static

  1. Tancapkan ujung kabel LAN Cross pada port Ethernet Laptop A dan Laptop B.
  2. Di kedua laptop, buka Control Panel > Network and Sharing Center > Change adapter settings.
  3. Klik kanan pada Ethernet > Pilih Properties > Klik 2x pada Internet Protocol Version 4 (TCP/IPv4).
  4. Atur IP Static sebagai berikut:
    • Laptop A: IP = 192.168.1.1 | Subnet Mask = 255.255.255.0
    • Laptop B: IP = 192.168.1.2 | Subnet Mask = 255.255.255.0

Step 2: Pengecekan Keterhubungan (Ping Test)

Untuk memastikan kedua laptop sudah saling terhubung:

  1. Buka Command Prompt (CMD) pada Laptop A.
  2. Ketik perintah: ping 192.168.1.2 lalu tekan Enter.
  3. Jika muncul balasan Reply from 192.168.1.2: bytes=32 time<1ms TTL=128, maka kedua laptop sudah **sukses terhubung**. Jika Request Timed Out, periksa kembali kabel atau matikan Windows Firewall.

Step 3: Cara Transfer File (Folder Sharing)

  1. Klik kanan folder yang ingin dibagikan pada Laptop A > Pilih Properties.
  2. Masuk ke tab Sharing > Klik tombol Advanced Sharing.
  3. Centang opsi Share this folder, lalu klik Permissions dan atur ke Full Control / Read.
  4. Di Laptop B, buka File Explorer dan ketik di address bar: \\192.168.1.1 lalu tekan Enter.
  5. Folder yang dibagikan akan muncul dan file siap diakses/diunduh secara langsung.
